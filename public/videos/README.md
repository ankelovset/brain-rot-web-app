# Videos Folder

Place your video files in this folder.

## Setup Instructions

Simply add your video files to this folder - they will be automatically detected and available for the survey!

The survey will randomly select one video from all files in this folder when a user starts the survey.

## Supported Formats

The video player supports standard HTML5 video formats:
- MP4 (recommended)
- WebM
- OGG
- MOV
- AVI

## How It Works

- Videos are automatically detected when the survey loads
- One video is randomly selected for each survey session
- The selected video filename is stored with the survey response
